#### Priority Issues

**[P2] Hero h1 exceeds display ceiling**
- **Why it matters**: The hero h1 uses `clamp(4rem, 8vw, 7rem)`. The 7rem max (~112px) exceeds the recommended 6rem ceiling. On large viewports, the name will feel like it's shouting rather than designing.
- **Fix**: Cap the clamp max at `6rem`: `clamp(4rem, 8vw, 6rem)`.
- **Suggested command**: `/impeccable typeset index.html`

**[P2] Bounce animation on scroll-down chevron**
- **Why it matters**: The `@keyframes bounce` on `.scroll-down` is a generic, overused animation pattern. It's the kind of motion that says "template" rather than "designed." Also lacks a `prefers-reduced-motion` alternative.
- **Fix**: Replace with a subtle, single-direction fade-and-slide that respects `prefers-reduced-motion`, or remove the animation entirely and let the chevron be a static affordance.
- **Suggested command**: `/impeccable animate index.html`

**[P2] No mobile navigation**
- **Why it matters**: `.nav-links` is set to `display: none` on mobile with no hamburger menu or alternative. Mobile users lose all navigation context.
- **Fix**: Add a hamburger toggle that reveals nav links on mobile, or convert to a horizontal scrollable nav strip.
- **Suggested command**: `/impeccable adapt index.html`

**[P3] Dead CSS rules from old layout**
- **Why it matters**: `.highlight-card`, `.highlight-card:hover`, `.highlight-card i`, `.highlight-card p`, `.cards-grid`, `.card`, `.card:hover`, `.card-header`, `.year`, `.card ul`, `.card li` are all orphaned rules from the old card grid and projects section. They add weight and confusion.
- **Fix**: Remove all dead rules.
- **Suggested command**: `/impeccable polish index.html`

**[P3] Duplicate `p` rule in CSS**
- **Why it matters**: Two separate `p` selectors exist (one with `max-width`/`text-wrap`, another with `margin-bottom`). The second overrides nothing but creates maintenance confusion.
- **Fix**: Merge into a single `p` rule.
- **Suggested command**: `/impeccable polish index.html`
