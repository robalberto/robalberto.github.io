#### Priority Issues

**[P3] No active-state indicator on nav links**
- **Why it matters**: Users don't get visual feedback about which section they're currently viewing.
- **Fix**: Add an IntersectionObserver-based active state that highlights the current nav link.
- **Suggested command**: `/impeccable polish index.html`

**[P3] Highlight icons still somewhat generic**
- **Why it matters**: The Font Awesome icons (server, microscope, users) are functional but don't add much personality.
- **Fix**: Consider custom SVG icons or a more distinctive icon set that matches the technical/cybersecurity theme.
- **Suggested command**: `/impeccable typeset index.html`
